Автор: Sofija

🔧 Как подключить

Добавьте репозиторий в вашу систему:

sudo xbps-install -S --repository=https://sofijacom.github.io/void-package/repo/x86_64 пакет

Пример:

sudo xbps-install -S --repository=https://sofijacom.github.io/void-package/repo/x86_64 google-chrome

📦 Доступные пакеты (x86_64)

  • google-chrome — Google Chrome (проприетарный)
  • brave-browser — Приватный браузер
  • github-desktop — Официальный клиент GitHub
  • mullvad-browser — Анонимный браузер
  • zoneminder — Домашняя автоматизация

📂 Репозиторий

Файлы доступны по:

  • repodata — метаданные
  • Все пакеты (.xbps, .sig2)
