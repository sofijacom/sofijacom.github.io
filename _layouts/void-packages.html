📦 Void Linux — Custom Packages

Автор: Sofija

🔧 Как использовать

Добавьте репозиторий в вашу систему:

xbps-install -S -r /tmp/test --repository=https://sofijacom.github.io/repo/x86_64

Или установите пакет напрямую:

sudo xbps-install -S --repository=https://sofijacom.github.io/repo/x86_64 google-chrome

📦 Доступные пакеты (x86_64)

  • google-chrome — Google Chrome (проприетарный)
  • brave-browser — Приватный браузер
  • github-desktop — Официальный клиент GitHub
  • mullvad-browser — Анонимный браузер от Mullvad
  • zoneplus — Пакет для домашней автоматизации
